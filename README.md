# 电商用户行为数据分析
> 大一软件工程（大数据方向）练习项目，使用Python Pandas完成数据清洗、指标统计与可视化

## 项目介绍
本项目使用公开电商数据集，模拟电商平台用户行为分析。
- 对原始脏数据进行清洗：缺失值、重复数据过滤
- 统计核心指标：总访问量、用户购买转化率、热门商品排行
- 使用Matplotlib生成可视化图表，输出分析结论

## 使用技术
- Python
- Pandas 数据处理
- Matplotlib 可视化
- MySQL（可选，结果入库）

## 如何运行 
1. 安装依赖包：`pip install pandas matplotlib`
2. 运行 `analysis.py` 执行数据分析
